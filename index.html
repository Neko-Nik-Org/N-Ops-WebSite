    [02] Capabilities

    Everything you need to run infrastructure.

    Ten tools you'd normally glue together with scripts and hope — designed from day one to share one model of your fleet.

    01 / 10

    Server Administration

    Install a lightweight agent and the server appears — OS, kernel, architecture and hostname detected automatically, labelled and grouped as test, staging or production.

    02 / 10

    Secrets Management

    AES-256-GCM at rest, scoped by project → service → environment, versioned with rollback, injected at deploy.

    DATABASE_URLprod
    ••••••••••••••••••••••
    hover to decrypt · audited
    03 / 10

    Configuration Deployment

    Diff, review and roll out config to a server group. Bulk-edit variables, import or export .env — with automatic rollback.

    /etc/nginx/nginx.conf
    - worker_processes 2;
    + worker_processes auto;
    + keepalive_timeout 30;
    Deployed to 12 servers · 3.1s
    04 / 10

    Docker Orchestration

    Start, stop, restart and scale containers across every host. Discovers Compose projects and inspects images, networks and volumes — Docker or Podman.

    apiapiapi
    webweb
    redisqueuecron
    pgpgbouncer
    05 / 10

    Logs & Monitoring

    Stream logs from every host and see the metric right next to the line that explains it. Custom extensions — like a Postfix mail-queue check — and offline-agent alerts, too.

    req/s · web2,481
    06 / 10

    Remote Operations

    One command, one host or a hundred — with a browser-based PTY and explicit confirmation before anything dangerous runs.

    [04] How it works

    Install. Connect. Control.

    From zero to a managed fleet in about the time it takes to read this section.

    01

    Install

    Self-host with one command, or start on Managed Cloud in a minute.

    $ curl -fsSL get.n-ops.dev | sh
    02

    Connect

    Add servers with a lightweight agent over secure, outbound-only channels.

    $ nops agent join --token ••••
    03

    Control

    Manage secrets, deploy config, orchestrate containers and automate — from one place.

    $ nops deploy ./config -g web
